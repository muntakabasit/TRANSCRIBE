## Actual spatial decisions under pressure

**01 / Library, the entrance:** The person's material should lead. Only one search entry, no repeated long technical explanation, no mandatory categories, and no Feed tab presented as a working destination during its hold. The material kinds do not all need matching card outlines. A direct frame-to-Watch and excerpt-to-Read gesture should each have their own hit area rather than inheriting a global reader-first row tap.

**02 / Source, the work itself:** The video can dominate when actually retained; readable text, original audio and original link remain properly distinguished. We don't invent generated narration or quality approval. Transcript versions is a truthful reachable second-level detail, not a badge that crowds the film.

**03 / Link-only, the truth of absence:** Even when remote media is unavailable, a source can remain meaningful and findable. No promise of media bytes from a saved URL, and no false download complete state. The absent capability is expressed *by the missing Watch action*, not an alarming error hero.

**Visual tone:** bone/charcoal/sage as study materials, not a frozen DAWT brand. The authored vector “scene” supplies a visual reading of space and human presence without pretending it is a user image. No stock imagery, glossy glass cards, AI chatbot face, inflated status dashboards, gamification or mandatory response actions.

**Typography / accessibility caveat:** vector art rendered to a fixed 420×930 canvas is a visual *specimen*, not Dynamic Type or VoiceOver proof. The same design must still survive native semantic controls, hit sizes, landscape/video ratio, Reduced Motion and actual-screen text reflow. The current boards are **not tappable prototypes**. Don't call them QA-passed.
